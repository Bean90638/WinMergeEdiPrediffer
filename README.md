# WinMerge EDI 規則管理器

讓不同 EDI 使用不同的比對規則，例如忽略流水號。可建立多個「組」，每組放多條規則；只處理比對用的內容，不修改 EDI 原檔。

## 1. 第一次使用

電腦需有 **Windows x64、官方 WinMerge x64（整合驗證版本：2.16.58.2）、.NET 10 Desktop Runtime x64 與 .NET 10 Runtime x64**。

管理器為每個啟用的組產生獨立 COM 外掛入口，官方 WinMerge 透過 `PluginFileFilters` 依原始路徑選入口，再處理比對內容。資料夾與單檔比對都不需要客製 WinMerge 或 `PluginOriginalFilePath`。升級方式見 [官方 WinMerge 相容性與移轉](docs/original-path-host.md)。

1. 拿到已建置程式時，請保留整個程式資料夾，包含 `Plugin` 子資料夾。
2. 雙擊 `WinMergeEdiPrediffer.Manager.exe`，按「開啟設定」載入交接的 `profiles.json`。
3. 第一次套用前關閉 WinMerge，按「套用到 WinMerge」，再開啟官方 WinMerge 比對檔案。

若只有原始碼，先安裝 **.NET SDK 10.0.401**、**Visual Studio C++ x64 建置工具**，在專案資料夾開啟 PowerShell 執行：

```powershell
dotnet build .\WinMergeEdiPrediffer.slnx -c Release
if ($LASTEXITCODE -ne 0) { throw '建置失敗' }
Start-Process .\src\WinMergeEdiPrediffer.Manager\bin\Release\net10.0-windows\WinMergeEdiPrediffer.Manager.exe
```

交接程式時，複製整個 `src\WinMergeEdiPrediffer.Manager\bin\Release\net10.0-windows` 資料夾，另附 `profiles.json`。

## 2. 設定與套用

1. 上方按「新增組」，勾選「啟用」，填入組名稱與路徑正則。拖曳最左側的 `≡` 調整組順序。
2. 選定組後，下方按「新增規則」，填入「尋找」與「取代」。同組可重複新增，拖曳最左側的 `≡` 調整規則順序。
3. 使用範例正則時，規則也要勾選「啟用」與「正則」；普通文字替換則取消「正則」。需要不分大小寫時勾選「忽略大小寫」。
4. 按「測試預覽」（Ctrl+T），填入完整檔案路徑，再載入檔案，確認選到的組及替換結果。
5. 按「套用到 WinMerge」，查看狀態列與比對結果；需要時按 F5 重新比對。

**Ctrl+S 只儲存設定，還要按「套用到 WinMerge」才會生效。** 修改設定後，請重新開啟預覽。

點選「完整路徑＋檔名正則」、「尋找」或「取代」儲存格，按 **Ctrl+C** 只複製該欄的純文字，不含整列、標題或表格。正在編輯文字時可選取部分內容複製。

## 3. 設定範例

「正則」是文字比對的寫法。以下可直接貼進管理器，再改成自己的檔名與資料夾。

### 建立三個組

各組勾選「啟用」；兜底組可先不放規則，依下表順序排列。

| 組名稱 | 完整路徑＋檔名正則 |
| --- | --- |
| EDI 850 | `\\A_850\.edi$` |
| EDI 860 | `\\A_860\.edi$` |
| 其他檔案 | `.*` |

前兩組匹配任何資料夾下的指定檔名。若 850 只處理指定資料夾，改用：

```text
^D:\\ProjectGit\\Brad\\EDI\\(old|new)\\A_850\.edi$
```

這會匹配 `D:\ProjectGit\Brad\EDI\old\A_850.edi` 與 `new\A_850.edi`。路徑中的 `\` 要寫成 `\\`。

路徑正則使用 .NET／WinMerge PCRE 的共通語法：支援 `\\`、`\.`、`.*`、群組、字元類別、前後查找、數量詞，以及開頭的 `(?i)`。路徑不分大小寫；`\d`、`\w`、`\s` 使用 ASCII 字元語意，管理器會轉換成不受 WinMerge 大寫處理影響的形式，分號也會安全編碼。具名群組、Unicode 類別、其他內嵌選項等不相容語法會在套用前明確報錯。**內容規則仍使用完整 .NET 正則**。

**啟用的組由上往下比對；每個檔案只用第一個符合的組。** 新組的路徑預設為 `.*`（任何檔案），請按需要修改。路徑 `.*` 的組放最後即可作為兜底，放前面則會先命中、擋住後面的組。組內啟用的規則由上至下執行。

舊版的「預設組」勾選會強制最後才比對，與單純填 `.*` 不同。新版移除優先序與預設組欄位；載入舊設定時，依舊版優先序及預設組位置轉成等效排列，保留原本的選組結果。儲存後使用 Schema 2，只記錄顯示順序。

### 同組新增兩條規則

選擇 EDI 850 組，新增下面兩條規則，兩條都勾選「啟用」與「正則」。此範例用於以 `*` 分隔欄位、以 `~` 結束段落的 EDI。

```text
規則 1：忽略 ST02 流水號，保留 ST01 類型
尋找：(^|~)(ST\*[^*~\r\n]+\*)[^*~\r\n]*
取代：$1$2<IGNORE>

規則 2：忽略 SE02 流水號，保留 SE01 數量
尋找：(^|~)(SE\*[^*~\r\n]+\*)[^*~\r\n]*
取代：$1$2<IGNORE>
```

例如 `ST*850*0001~SE*16*0001~` 比對時會變成 `ST*850*<IGNORE>~SE*16*<IGNORE>~`。`$1$2` 代表保留找到的前段內容；原檔不變。規則逐行處理，取代內容不可加入換行。

完整 JSON 範例在 `examples\profiles.example.json`；日常設定使用管理器即可。

## 4. 常見問題與資料保留

- **改了沒生效：** 確認組與規則已啟用、按過「套用到 WinMerge」，再按 F5。其他比對分頁需切換後各按 F5；自動刷新支援 WinMerge 2.16.58.2。
- **要求關閉 WinMerge：** 首次從舊 Router 升級、更新 DLL 或修復安裝可能需關閉一次；日常新增／刪除組、改路徑／順序／啟用狀態及內容規則均不必重開。選組條件變更時若擴充功能設定視窗開著，請關閉該視窗再按套用。
- **外掛清單有多個 EDI 外掛：** 正常，每個啟用的組都有獨立入口；互斥的篩選器保證只選第一個命中的組。已載入後刪除的入口暫保留為停用，關閉 WinMerge 後下次套用會清理。
- **測試資料有換行：** 預覽支援載入與貼上的 CRLF、LF、CR 及混合換行；原始內容與逐步結果均分行顯示，複製時保留原始換行格式。原始檔案不會被寫入。
- **交接或搬動：** 保留 `profiles.json` 與整個程式資料夾；搬到新位置後重新套用。設定與安裝備份位於 `%APPDATA%\WinMergeEdiPrediffer\backups`，請保留。
- **停止使用：** 關閉管理器即可；已套用的規則仍會供 WinMerge 使用。
